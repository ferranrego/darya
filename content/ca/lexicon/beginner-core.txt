# Catalan beginner core
#
# The words a learner needs on day one, which corpus frequency does not
# surface. The ranking in lexicon.json is blended from subtitles and
# Wikipedia and is correct as frequency - but the head of it is abstract
# discourse vocabulary (estat, cosa, part, vegada, manera, guerra, punt,
# acord, sistema, empresa), because concrete nouns are simply rarer in
# written text than abstract ones. Measured: of these words 138 are in the
# lexicon and 80 of them rank past L1, so "El gos menja carn" and
# "Quant costa la poma?" were not expressible at the level they belong to.
#
# So this is additive and explicit. Tagging a word `beginner-core` lets the
# first two levels teach it whatever its rank; it does not change freqRank,
# which every level above depends on, and it does not make the word count as
# already known.
#
# One headword per line. Anything the lexicon lacks is reported by
# scripts/tag-beginner-core.ts rather than silently skipped.
